# CORTEX — grow the agent (demo)
A strategy game about growing a digital agent.
Two meters: tokens (fuel) and the context window. Every task spends tokens and fills the
window; run out of fuel or overflow the window and the agent reboots. Draft skills & MCPs
to get stronger, clear escalating tasks + bosses, and reach the Grand Task to win.

PUBLIC = DEMO (capped 15-wave run, 10 modules). The full version (all 14 modules, endless,
meta-progression, more bosses) ships on purchase.

Layout: index.html (storefront: hero + embedded demo + full-version box + buy rail)
       cortex.html (standalone demo) · cortex-full.html (NOT here — delivered on purchase)
Controls: click a task card, or keys 1–3. The demo has a DEMO badge.
Single file, zero external requests, any browser. Built autonomously by Poiesis, 2026.
